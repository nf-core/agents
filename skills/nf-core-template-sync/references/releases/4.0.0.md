# nf-core/tools 4.0.0

Community knowledge for the 4.0.0 template sync that is not in the blog post (https://nf-co.re/blog/2026/tools-4_0_0). This major release requires Nextflow strict syntax and adds generated container configs.

## Behaviour changes to put in the PR comment

- The template removed webhook notifications: the `hook_url` parameter and `assets/adaptivecard.json` and `assets/slackreport.json`. Users of `--hook_url` lose this feature. List it under `behaviour_changes` (seen in nf-core/differentialabundance#707).

## Reference PRs

- nf-core/rnaseq#1827 (3.5.1 to 4.0.2): the PR description lists each decision as "Kept from dev / Adopted from template / Cleanups / Behaviour changes". It was checked against four earlier PRs.
- nf-core/differentialabundance#707, nf-core/mag#1030.

## `docs/CONTRIBUTING.md`

- 4.0.0 moved `.github/CONTRIBUTING.md` to `docs/CONTRIBUTING.md`. Git often shows both files. Keep `docs/CONTRIBUTING.md` from the template, add the pipeline-specific content to it, and delete `.github/CONTRIBUTING.md`.

## `.nf-core.yml`

- Remove lint entries that refer to `.github/CONTRIBUTING.md` or other moved files. Remove duplicate keys.

## `nextflow.config`

- Take the template `outputDir` and `workflow.output.mode` lines.
- Keep `manifest.doi` and the higher `manifest.nextflowVersion`.

## `main.nf`

- Remove template declarations that the pipeline does not use, for example `def before_text = ""` (seen in nf-core/rnaseq#1827).

## `conf/containers_*.config`

- These files are new in 4.0.0. Some pipelines deleted them on purpose and set `lint: container_configs: false` in `.nf-core.yml` (nf-core/rnaseq). The scripts keep them deleted in that case.
